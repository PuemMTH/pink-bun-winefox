# Satou · YSM reference pack v1

เปิด **index.html** เพื่อดูสารบัญภาพ ค้นหาชื่อท่า และกรองชุด/หมวดได้ทันที ไม่ต้องติดตั้งแพ็กเกจหรือเชื่อมอินเทอร์เน็ต กดรูปเพื่อดู PNG เต็มขนาด

## สิ่งที่รวมไว้

- **2 ชุด:** ชุดนักเรียน และเชิ้ตขาวอยู่บ้าน
- **26 ชีต / 156 ภาพย่อย:** รวมภาพชุดเดิมที่เลือกไว้และภาพที่สร้างเพิ่มด้วย built-in image_gen
- **25 คลิปหลักต่อชุด:** รวมท่ายืน เดิน วิ่ง กระโดด ย่อ นั่ง บิน ว่ายน้ำ ปีน นอน ขี่ ใช้มือ และสถานะตอบสนอง/ลอยตัว
- **8 extra states ต่อชุด:** ตาม metadata ของโมเดลต้นทาง รวมเคสสลับ/รีเซ็ตอุปกรณ์ศีรษะ extra0
- **6 โพสถ่ายรูปต่อชุด:** ทักทาย แนบแก้ม เท้าเอว ประสานมือ มือแนบอก และกางแขน
- **8 สีหน้าต่อชุด:** ปกติ ยิ้ม ประหลาดใจ กังวล หลับตา ขยิบตา ก้นหอยหน้านิ่ง และก้นหอยยิ้ม
- **ชีตรายละเอียด:** คอปก โบ/กระดุม แขน/ปลายแขน ชายผ้า และผมด้านหลัง
- **checklist.csv:** 138 เคสเริ่มที่ pending พร้อมช่องผลตรวจ ภาพโมเดลจริง และหมายเหตุ

## ใช้อย่างไร

1. เริ่มจากชีต turnaround ของชุดนั้นเพื่อเทียบสัดส่วน ผม และทรงชุด
2. เทียบสีหน้ากับชีต facial states แยกจากท่าทาง ภาพคอนเซปต์เก่าบางภาพเปิดตาก้นหอยเพื่อสื่อบุคลิก ไม่ได้กำหนดว่าทุกแอนิเมชันต้องเปิดตาก้นหอย
3. ตรวจท่ายืน/เดิน/วิ่ง/กระโดด/ย่อ/นั่งจาก 3 มุม แล้วตรวจคลิปอื่นจากตาราง action
4. ถ่ายภาพ YSM จริงลง actual-screenshots/ และกรอกผลใน checklist.csv ดูรายละเอียดใน CHECKLIST.md
5. ติ๊ก “ตรวจชีตนี้แล้ว” ในสารบัญเพื่อบันทึกความคืบหน้าในเบราว์เซอร์ของเครื่อง การติ๊กไม่ใช่การให้ทุกเคสผ่าน

ภาพในแพ็กเป็นคอนเซปต์ AI สำหรับเทียบรูปลักษณ์ ไม่ใช่ผลเรนเดอร์ rig แบบวัดองศาได้ตรง 1:1 และยังไม่ได้เป็นหลักฐานว่าโมเดล YSM จริงผ่านการทดสอบ ส่วนท่าสำหรับม็อดเสริม TaC / Carry On / keyboard มีรายชื่อใน COVERAGE.md และ clip-catalog.json เพื่อทดสอบแยกใน runtime ของม็อดนั้น

## ไฟล์ประกอบ

- index.html — สารบัญภาพและตัวกรอง
- CHECKLIST.md / checklist.csv — คู่มือและผลตรวจรายเคส
- COVERAGE.md / clip-catalog.json — รายชื่อคลิปต้นทางและขอบเขต
- manifest.json — ขนาดไฟล์ ความละเอียด SHA-256 และรหัสแต่ละภาพย่อย
- PROMPTS.md / plan.json — พรอมป์ตกับภาพอ้างอิงสำหรับสร้างซ้ำ
- palette-source.json — สีและค่าตั้งโมเดลต้นทาง ชุดเชิ้ตขาวเป็นคอนเซปต์เพิ่มจึงยังไม่มี texture atlas จริงในโมเดลต้นทาง
- images/ — PNG ทุกชีต ใช้ได้โดยไม่ต้องดึงไฟล์จากโฟลเดอร์อื่น
- actual-screenshots/ — เตรียมไว้ใส่ภาพโมเดลจริง

แก้ข้อมูลแพ็กใน plan.json แล้วรัน `node build.cjs` เพื่อสร้างสารบัญ/manifest/CSV ใหม่ คำสั่งนี้จะสร้าง checklist.csv ใหม่ จึงควรสำรองผลตรวจที่กรอกแล้วก่อนรัน
