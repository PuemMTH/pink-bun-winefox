# วิธีตรวจโมเดล YSM กับภาพอ้างอิง

1. เปิด `index.html` เลือกชุดและหมวด กดภาพเพื่อดูเต็มขนาด ภาพเป็นคอนเซปต์ AI สำหรับเทียบรูปลักษณ์ ไม่ใช่ผลเรนเดอร์กระดูกที่ต้องตรงทุกพิกเซล
2. โหลดโมเดลจริงใน YSM และถ่ายด้านหน้า/ข้าง/หลังด้วยระยะกล้องใกล้เคียงกัน เก็บภาพไว้ใน `actual-screenshots/`
3. เปิด `checklist.csv` ใน Excel/Sheets ใส่สถานะ `pass`, `fail` หรือ `not-applicable` พร้อมพาธภาพจริงและหมายเหตุ ช่องเริ่มต้นเป็น `pending` ทั้งหมด การมีภาพอ้างอิงไม่ได้หมายความว่าโมเดลผ่านแล้ว
4. เช็กทั้งภาพค้างและตลอดวงรอบแอนิเมชัน โดยเฉพาะช่วงก้าวสุด เข่างอสุด การเปลี่ยนท่า และตอนสลับกลับยืน
5. ติ๊ก “ตรวจชีตนี้แล้ว” ในสารบัญเพื่อจดความคืบหน้า ข้อมูลนี้เก็บในเบราว์เซอร์ของเครื่อง ไม่อัปโหลด การติ๊กหมายถึงตรวจครบแล้ว ไม่ใช่ยืนยันว่าทุกเคสผ่าน

## สัดส่วนและชุด

- ผมมวยคู่ หน้าม้า และผมด้านหลังใช้ระนาบเหลี่ยมและเงาพิกเซล สัดส่วนหัว/ขาไม่แกว่งระหว่างชุด
- ชุดนักเรียน: โบต้องอยู่หน้าเสื้อ เสื้อกั๊ก/ขอบทอง/แขนเสื้อไม่ซ้อนผิด กระโปรงไม่เปิดหรือมีขาทะลุตอนเดิน วิ่ง กระโดด ย่อ และนั่ง
- ชุดเชิ้ตขาว: คอปก กระดุม ปลายแขน และชายเสื้อยาวคงรูป เงาขาว/เทาอมม่วงอ่านได้ ไม่กลับเป็นพื้นผิวชุดนักเรียน ชายเสื้อคลุมตามปกติตลอดท่า
- ไม่มีชิ้นโพลิกอนเล็กถี่หรือผิวโค้งละเอียดหลุดสไตล์บริเวณใต้ชายผ้า ไม่มีลาย UV ยืด รอยต่อโปร่ง หรือแสงกะพริบจากผิวทับกัน

## สีหน้า

- ตรวจตาปกติ/ตาก้นหอยแยกจากท่าทาง หน้าแบบก้นหอยในภาพคอนเซปต์เก่าบางภาพเป็นการศึกษาบุคลิก ไม่ใช่ข้อบังคับว่าท่านั้นต้องเปิดตาก้นหอยเสมอ
- ปาก/คิ้ว/เปลือกตาไม่ซ้อนหลายแบบ ดวงตาสองข้างอยู่ในตำแหน่งเดิม ไม่มีดวงตาปกติโผล่ผ่านหน้ากากก้นหอย
- ทดสอบ ปกติ → ก้นหอย → ปกติ และลืมตา → หลับตา/ขยิบตา → ลืมตา ตรวจว่าคืนค่าได้ครบ
- ตารางสีหน้า 8 แบบเป็นเป้าหมายออกแบบสำหรับโมเดลรุ่นถัดไป ไม่ใช่คำยืนยันว่าทั้ง 8 แบบมีระบบสลับในโมเดลปัจจุบันแล้ว

## แอนิเมชัน

- ตรวจ 25 คลิปหลักทั้งสองชุดตาม CSV และ 8 extra states; extra0 คือการสลับ/รีเซ็ตอุปกรณ์ศีรษะ ไม่ได้กำหนดให้เพิ่มหมวกหรือหูสัตว์
- ท่า nod/shake/clap/sway/dance ต้องตรวจการเคลื่อนต่อเนื่อง ภาพนิ่งบอกได้เพียงเฟสหนึ่ง
- โพสถ่ายรูป 6 แบบเป็นโพสที่เพิ่มในเว็บ ยังต้องนำไปสร้างแอนิเมชัน YSM หากต้องการใช้ในเกม
- เอฟเฟกต์การถือของและม็อดเสริม TaC/Carry On/keyboard ต้องตรวจใน runtime ที่เกี่ยวข้อง ดูรายการใน `COVERAGE.md`

## สิ่งที่ส่งต่อเมื่อพบปัญหา

ระบุชุด, clip/face ID, เฟรมหรือช่วงเวลา, มุมกล้อง, ภาพจริง, จุดที่ต่างจากเป้าหมาย และผลที่ต้องการ เช่น “white / run / side / 0.17 s — ชายเสื้อตัดผ่านเข่า”
