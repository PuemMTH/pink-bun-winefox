# Working on this model

- Use `npm test` for the build and geometry regression checks; use `npm run pack` to refresh the downloadable ZIP.
- Edit `model.config.json`, `src/`, or `vendor/winefox-jk/`. Do not use `dist/` as the source of truth.
- Preserve original author metadata and CC BY-NC-SA 4.0 attribution.
- Never commit `local.config.json`, `local-backups/`, authentication data, or machine-specific paths.
- Update the normal/sprint previews and ZIP when publishing model changes.
- Report numerical geometry checks separately from in-game visual testing. Do not claim the latest model was tested in Minecraft unless it was actually observed.
